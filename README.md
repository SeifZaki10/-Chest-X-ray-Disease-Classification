# 🩻 Chest X-ray Multi-Label Disease Classification

A deep learning web application for multi-label chest X-ray disease classification using DenseNet121 and TensorFlow.

## 🚀 Live Demo

https://seifzaki10--chest-x-ray-disease-classification-app-othksj.streamlit.app/

## 📂 GitHub Repository
https://github.com/SeifZaki10/-Chest-X-ray-Disease-Classification

---

## 📌 Project Overview

This project predicts multiple thoracic diseases from a single chest X-ray image using a DenseNet121 model with transfer learning.

The application allows users to upload a chest X-ray image and receive the predicted diseases with their confidence scores.

---

## 🧠 Model

- DenseNet121 (Transfer Learning)
- TensorFlow / Keras
- Multi-label Classification
- Sigmoid Activation
- Binary Cross-Entropy Loss

---

## 📊 Dataset

The model was trained on the NIH Chest X-ray Dataset containing 14 thoracic disease classes.
